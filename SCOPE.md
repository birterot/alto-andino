# Scope: coffee journal, version 1

Version 1 is done when we have both used it for two weeks without changing it.

## Capture (the data must be complete from day one)
- Coffee: name, origin, blend, processing method, roast level, flavour notes as tags (for example sour, sweet, balance, chocolaty, bitter), roast date, open date, bag photo
- Brew log: date (automatic), device (for example Flair), recipe (grind, pressure, dose, yield, time), notes, and a score from 0 to 10 for each flavour tag of the coffee plus the core four (sour, sweet, bitter, balance)

## Show
- Timeline per coffee: every brew in order, with days since roast and days since open

## Also in version 1
- Login for two people
- The coffee atlas stays part of the same site

Nothing else is in version 1. New ideas go into LATER.md.
